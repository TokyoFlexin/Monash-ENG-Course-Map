# Monash Engineering Course Map

A course planner for Monash Engineering (Honours) — you place units into a
Year × Semester grid yourself; the catalog knows real Handbook data (credit
points, prerequisites/corequisites/prohibitions, semester offering) and flags
issues as you go, but never blocks placement.

**Live**: https://tokyoflexin.github.io/monash-course-map/

Phase 1: Electrical & Computer Systems Engineering (E3007, single degree),
plus an in-progress Commerce side for a possible E3005 double-degree transfer.

Working with Claude Code: see `CLAUDE.md` to get oriented, then `INSTRUCTIONS.md`.
Progress is logged in `PROGRESS.md` — read that first, it's the source of truth.
